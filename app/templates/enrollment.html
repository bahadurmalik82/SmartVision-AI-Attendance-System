How classes work

A class is one group you teach — for example BS Computer Science - AI, Section B, Semester 5. Make a separate class for Section C, for Semester 3, or for a different department. Students are enrolled into a class (one by one, or by CSV), and each class has its own student list. When a class moves to a new semester, create a new class for it — do not edit the old one — so last semester's students and attendance stay saved until you delete that class yourself.

Student login is automatic

When you save a student, the system gives them a unique CMS ID (CMS-0001, CMS-0002, ...) and a random password. Share both with the student — they log in with them on the Student Portal. You can see every student's CMS ID and password on their class page.

Bulk Import Students (.csv)

Upload a CSV of students to add them all to one class at once. Columns: roll_number, name, department, semester, section, email, password — only roll number and name are required; a blank password means a random one is made for that student. Every imported student gets a CMS ID and password.

Bulk Face Enrolment — 3 photos per student

Upload one ZIP containing photos.csv and the photos. Each row of photos.csv names one student and their 3 photos: roll_number, front, left, right — for example 023-24-0001, 023-24-0001_front.jpg, 023-24-0001_left.jpg, 023-24-0001_right.jpg. A student is enrolled only when all 3 photos are in the ZIP, are real images, and pass the sharpness check. If a student has a problem, that student is skipped and reported below — the other students still get enrolled.
